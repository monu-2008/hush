PRIVATE BY DESIGN

A private note, carried in plain sight.

Hush is a browser-based tool for encrypting a message and carrying it with an emoji or an image. The note is encrypted before you copy or download the container.

01

Write and encrypt

Enter your note and a strong password. Hush uses your browser’s Web Crypto API to encrypt the note on your device.

02

Choose a familiar carrier

Copy an emoji message with invisible encrypted characters, or download a PNG container. You can also use your own image as the visible carrier.

03

Share the password separately

The recipient pastes the complete emoji message or uploads the original PNG, then enters the password to decrypt the note in their browser.

YOUR DATA STAYS YOURS

No message uploads. No account required.

Hush is a static site. It does not send or store your message, password, or selected image on a server. The encrypted container is created locally in your browser.

GOOD TO KNOW

Frequently asked questions

Will every chat app preserve the hidden emoji message?

Not always. Some apps remove invisible characters. Send a test first, or use the PNG and share it as an original file or document.

Does Hush change the pixels in my photo?

The supplied-image option keeps the visible image pixels and stores the encrypted payload in a PNG metadata chunk. Recompression, screenshots, and format conversion can remove that payload.

Can Hush recover a forgotten password?

No. The password is never sent to Hush, so it cannot be recovered. Share it with the recipient through a separate trusted channel.
